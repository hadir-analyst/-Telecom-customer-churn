# Telecom Customer Churn Dashboard

An interactive Power BI dashboard analyzing customer churn for a telecom company, built to identify the key drivers behind customer loss and support retention strategy decisions.

##  Contents

- **`telecom_customer_churn.pbix`** — The full interactive Power BI report.
- **`02-Churn-Dataset.xlsx`** — The source dataset used to build the report.

##  What's Inside

The dashboard explores customer churn across dimensions such as contract type, tenure, services subscribed, payment method, and billing, helping to surface patterns in why customers leave and which segments are most at risk.

##  How to Use

1. Download `telecom_customer_churn.pbix`.
2. Open it in [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) (free).
3. Explore the report pages, filters, and visuals interactively.

##  Data Source

The dataset (`02-Churn-Dataset.xlsx`) contains customer-level telecom data including demographics, account information, services used, and churn status.
